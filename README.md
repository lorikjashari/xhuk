## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local web server (optional, but recommended)

### Installation

1. **Clone or download** the project files to your local machine

2. **Open the project:**
   ```bash
   cd XhukEntertaiment
   ```

3. **Run with a local server (recommended):**
   
   **Option A - Using Python:**
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   ```
   
   **Option B - Using Node.js (with http-server):**
   ```bash
   npx http-server -p 8000
   ```
   
   **Option C - Using VS Code:**
   - Install "Live Server" extension
   - Right-click `index.html` and select "Open with Live Server"

4. **Open in browser:**
   ```
   http://localhost:8000
   ```

### Direct File Access
Alternatively, you can simply open `index.html` directly in your browser by double-clicking the file. However, some features may work better with a local server.

## 🎨 Customization Guide

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --neon-blue: #00d9ff;
    --neon-purple: #b967ff;
    /* Add your custom colors */
}
```

### Content
- **Company Info:** Edit text in `index.html`
- **Leadership Team:** Update names, titles, and bios in the Leadership section
- **Services:** Modify service cards in the Services section
- **Portfolio:** Add/remove portfolio items and update categories

### Images
Replace placeholder images with your own:
- Leadership photos: Replace `https://via.placeholder.com/...` URLs
- Portfolio images: Update image sources in both HTML and `script.js`

### Contact Information
Update contact details in the Contact section:
- Address
- Phone numbers
- Email addresses
- Social media links

## 🛠️ Troubleshooting

### Particles not showing
- Ensure you have an internet connection (particles.js loads from CDN)
- Check browser console for errors
- Verify particles.js script is loading correctly

### Animations not working
- Ensure JavaScript is enabled in your browser
- Check for console errors
- Clear browser cache and reload

### Form not submitting
- Form currently shows success message without backend
- Integrate with a backend service for actual form submission
- Consider services like Formspree, EmailJS, or custom backend

### Mobile menu not working
- Check if JavaScript is enabled
- Verify screen width is below 768px
- Inspect console for errors
